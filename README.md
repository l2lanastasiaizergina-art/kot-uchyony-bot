# Кот Учёный — образовательный Telegram Mini App

Образовательное мини-приложение с орфографической игрой для 1–11 классов и
интерактивной «Библиотекой лидера». Проект рассчитан на Telegram
ID-авторизацию, сохранение прогресса, рейтинги и интервальные повторения.

> Релиз `0.4.0` добавляет первый зал «Библиотеки лидера»: 10 книг, 60 коротких
> сюжетных эпизодов и 100 интерактивных решений. Следующие залы расширят
> подборку до 100 книг.

## Что уже реализовано

- модульная структура `handlers / game / database / utils / data`;
- миграция SQLite и журнал начисления баллов с защитой от повторной записи;
- регистрация по Telegram ID, выбор класса, профиль;
- общий, классный и ежемесячный рейтинги Top-10;
- отдельные накопители общего и помесячного рейтинга;
- схема игровых сессий, ответов, викторин, рассылок и будущих прав доступа;
- 11 версионируемых JSON-пакетов, подготовленных из методических пособий;
- начисление `+10 / −2` и бонусы за серии 3, 5 и 10 ответов;
- ежедневная серия с множителем до `×2`, лиги, достижения и коллекции;
- персональная очередь повторения собственных ошибок;
- полный раунд из 10 заданий с inline-кнопками и прогрессом;
- автоматическая генерация трёх правдоподобных ошибок для каждого слова;
- атомарная фиксация ответа, защита от двойного клика и антиспам;
- итог раунда, множитель регулярности, лига и повторный запуск одной кнопкой;
- полноэкранный Telegram Mini App поверх той же SQLite-логики;
- главный экран с выбором между «Орфографией» и «Библиотекой лидера»;
- каталог первых 10 книг с последовательным открытием миссий;
- для каждой книги: вводная, 6 эпизодов, критический фильтр и финальный кейс;
- четыре варианта ответа без прокрутки, подсказка после первой ошибки и разбор;
- серверная проверка ответа без передачи правильного варианта в браузер;
- отдельный прогресс, баллы за первую попытку и повторения через 24 часа и 7 дней;
- отдельный режим 1–2 классов: крупные варианты в один столбец и визуальная подсказка;
- анимированные реакции Кота Учёного на ответ, серию и итог раунда;
- крупная зелёная карточка правильного написания после каждого ответа;
- проверка подписи Telegram `initData` на сервере;
- Dockerfile, Compose, MIT License и автоматические тесты.

## Быстрый запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[dev]"
cp .env.example .env
```

В `.env` укажите токен от `@BotFather` и Telegram ID администраторов:

```dotenv
BOT_TOKEN=1234567890:replace_with_botfather_token
ADMIN_IDS=123456789,987654321
WEBAPP_URL=https://your-public-domain.example
LEADER_LIBRARY_PATH=./data/leader_library/content.ru.json
```

Инициализация и проверка контента:

```bash
orthogame-init-db
orthogame-import-content
python -m unittest discover -s tests -v
```

Запуск:

```bash
python main.py
```

Локальный просмотр Mini App без Telegram:

```bash
python scripts/preview_webapp.py
```

Затем откройте `http://127.0.0.1:8080`. Режим предпросмотра использует только
локальную тестовую учётную запись и не должен включаться на production.

Либо через Docker:

```bash
docker compose up --build -d
docker compose logs -f bot
```

## Контент

Основной формат — `data/words/grade_XX.json`. Пакет имеет номер версии;
изменение существующего файла без повышения `version` блокируется, чтобы
случайно не исказить уже сыгранные задания.

Сценарии «Библиотеки лидера» собраны в
`data/leader_library/content.ru.json`. Клиент получает только текст текущего
этапа и четыре варианта; индекс правильного ответа и объяснение выдаются
сервером после завершения попытки. Прогресс хранится в таблицах
`leader_library_*` и не теряется между запусками.

```json
{
  "slug": "grade-01-base",
  "version": 1,
  "grade": 1,
  "title": "Орфографический минимум. 1 класс",
  "words": [
    {
      "id": "g01-...",
      "group": "ЖИ—ШИ",
      "rule": "Пиши И после Ж и Ш.",
      "answer": "жираф",
      "prompt": null,
      "orthograms": [{"start": 1, "end": 2, "text": "и"}],
      "distractors": [],
      "tags": ["grade:1", "ЖИ—ШИ"],
      "difficulty": 1
    }
  ]
}
```

Позже администратор сможет загружать такой JSON либо CSV через `/upload_words`.
CSV будет валидироваться и преобразовываться в ту же внутреннюю модель.

## Политика буквы «ё»

По умолчанию включён строгий режим: `ACCEPT_E_FOR_YO=false`. Буква `ё`
обязательна, поэтому ответ `береза` для слова `берёза` считается ошибкой.
Смягчить правило технически можно позднее, но в основном учебном режиме оно
отключено.

## Публикация на GitHub

Проект уже содержит `.gitignore` и открытую лицензию MIT. После создания пустого
публичного репозитория:

```bash
git init
git add .
git commit -m "Initial architecture and SQLite layer"
git branch -M main
git remote add origin https://github.com/USERNAME/kot-uchyony-bot.git
git push -u origin main
```

Токен бота никогда не добавляйте в Git: он должен оставаться только в `.env`
или в секретах платформы деплоя.
