# Создание «Кота Учёного» через BotFather

GitHub для создания Telegram-бота и Mini App не требуется. Нужны сам бот,
сервер с HTTPS-доменом для будущего Mini App и безопасно сохранённый токен.

## 1. Создать бота

1. Откройте официальный аккаунт [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Название: `Кот Учёный`.
4. Подберите свободное техническое имя, которое заканчивается на `bot`, например:
   `KotUchyonyBot`, `UchyonyKotBot` или `GramotnyKotBot`.
5. BotFather выдаст токен. Не пересылайте его в чаты и не добавляйте в Git.
   Позднее он будет записан на сервере как секрет `BOT_TOKEN`.

## 2. Оформить карточку

В BotFather последовательно вызовите:

- `/setdescription` — выберите бота и вставьте:

  ```text
  Кот Учёный — бесплатная орфографическая игра для 1–11 классов. Проверяй написание слов, собирай серии, поднимайся в рейтинге и докажи, что ты самый грамотный!
  ```

- `/setabouttext` — выберите бота и вставьте:

  ```text
  Орфографические челленджи, серии и рейтинги 🐈‍⬛📚
  ```

- `/setcommands` — выберите бота и вставьте:

  ```text
  start - открыть главное меню
  profile - моя статистика
  leaderboard - топ-10 игроков
  ```

- `/setuserpic` — загрузите квадратный аватар Кота Учёного, когда утвердим визуал.

## 3. Что понадобится для серверного запуска

- username созданного бота;
- Linux-сервер с Docker и постоянным диском или выбранная облачная платформа;
- способ безопасно внести `BOT_TOKEN` в секреты сервера;
- для Mini App — HTTPS-адрес веб-интерфейса.

На первом серверном запуске используем long polling. После появления HTTPS-домена
можно оставить polling либо перейти на webhook. Кнопку Mini App подключим через
BotFather только после публикации веб-интерфейса: Telegram требует действующий
HTTPS URL.
